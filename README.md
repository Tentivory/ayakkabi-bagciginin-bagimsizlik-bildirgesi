# T.C. Ayakkabı Bağcığı Bağımsızlık ve Çift Taraflı Düğüm Cumhuriyeti

## Resmi İlan

4 Temmuz 1776 küçük düşünülmüştür. Asıl devrim, sağ ayakkabının üstündeki bağcığın, sol ayakkabının üstündeki bağcıktan **resmen** ayrılmasıdır.

Bu yazılım, bağcığın kendi anayasasını, milli marşını, vergi tarifesini ve çözülme protokolünü üretir. Gerçekten çalışır. Gerçekten gereksizdir. İkisi birden ciddi bir iştir.

## Kurulum

```bash
python3 bagcik_cumhuriyeti.py
```

Bağımlılık yoktur. Sadece Python 3 ve biraz vicdan yeter.

## Kullanım

Program şunları sorar:

1. Hangi ayakkabı? (`sag` / `sol` / `terlik-kaos`)
2. Kaç düğüm vardır?
3. Bağcık bugün kendini nasıl hissediyor?

Sonra resmi bildiriyi basar. Yazıcınız yoksa bağcığın kendisine okuyabilirsiniz. Anlamaz ama damga yer.

## Bilimsel Dayanak

- ISO-BAGCIK-1776
- TS-DUGUM-404 (standart bulunamadı)
- Cenevre Bağcık Sözleşmesi (hayal ürünü, yine de imzaladık)

## Sık Sorulan Sorular

**Bağcık oy kullanabilir mi?**  
Hayır. Ama referandum yapar.

**Sol bağcık ne diyecek?**  
Protesto edecek. Bu da protokolün parçasıdır.

**Bu siyasi mi?**  
Hayır. Bu bir düğümdür. Siyaset düğüm çözer sanır; bağcık bilir ki düğüm sadece başka bir düğüm doğurur.
